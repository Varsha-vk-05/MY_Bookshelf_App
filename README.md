# 📚 Bookshelf App

A clean and user-friendly mobile application built as part of my internship journey. The Bookshelf App allows users to explore books, view detailed information, and read user feedback in an intuitive interface.

---

## 🚀 Features

* 📖 Browse a collection of books
* 🔍 View detailed book information
* 📝 Read user feedback and reviews
* 🎨 Clean and modern UI design
* 📱 Smooth navigation across screens
